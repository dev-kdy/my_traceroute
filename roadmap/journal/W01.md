# W01 학습 사건 기록 (초기 ChatGPT → Antigravity CLI 인계)

> **이력 스냅샷 / 2026-11-21 작성.** 아래 사건은 기존 ChatGPT 대화에서 **사용자가 제출한 답·터미널 출력**을 구조적으로 옮긴 것이다. Antigravity CLI가 사용자의 로컬 Rust crate 또는 네트워크를 실행했다는 증거가 아니다. 앞으로는 새 사건을 날짜·증거 유형·다음 과제와 함께 맨 아래에 추가한다.

## 현재 위치

- 주차: **W01 진행 중**, 다음 수업 **W01-L02**.
- 1차시 개념 학습·TTL 시뮬레이터 출력은 일부 확인, 독립 C 흐름 설명·실측/대체 패킷 관찰·최종 재평가는 미완료.
- 2차시 첫 번째 과제: `rustup show active-toolchain` 결과와 `rustc` vs `rustup` 차이를 자신의 말로 설명.
- 로컬 `Cargo.toml`/Edition/실제 Rust 소스 위치가 GitHub 원격 저장소에서 확인되지 않음. 새 crate를 만들기 전에 기존 로컬 crate 위치 확인.

## 이력 1 — 변수 가변성

**[사용자 답변]** `let domain = String::from("example.com");`으로 `mut`를 제거했으며, 컴파일 타임에 변경 가능성과 불변성을 구분하기 위한 것이라고 이유를 설명했다.

- 피드백: 핵심 정답. Java `final`과 Rust `let`은 완전히 동일하지 않음.
- 판정: **개념 답변 확인**, GitHub 실제 구현 변경은 미확인.

## 이력 2 — 실행 결과 제출

**[사용자 로그]** 목적지 `example.com`, TTL 1/2/3, 각 TTL에서 Probe 1/2/3, `trace finish!` 출력.

- 판정: **출력 기대와 일치**.
- 미확인: Cargo 빌드 전체 로그/실제 프로세스 종료 코드. 네트워크 패킷을 보낸 증거는 없음.

## 이력 3 — Toolchain·Cargo

**[사용자 로그]**

- `rustc --version` → 1.100.0.
- `cargo --version` → 1.100.0.
- `cargo fmt --check` 명령 실행을 보고했으나 종료 코드 미제출.
- `cargo clippy -- -D warnings` → `Checking my_traceroute v0.1.0` 후 `Finished dev profile`로 완료한 로그 제출.

**판정:** 버전/Clippy 로그는 `user_reported`; `fmt` **Exit Code는 unverified**. 에이전트가 다시 실행하지 않았으므로 `agent_observed`로 바꾸지 않는다.

## 이력 4 — 확인 문제와 보충

최초 진단 점수: **55/100**(이전 튜터의 진단 점수). 이후 보충 답변을 통해 TTL=1 실제 패킷은 **첫 번째 라우터에서 소진될 수 있음**을 맞혔다.

- 문제 1(`const`/`let mut`): 핵심 맞음.
- 문제 2(TTL/ICMP): 라우터 감소·폐기 이해, **ICMP Time Exceeded Type 11 Code 0** 정확한 명칭 보충 필요.
- 문제 3(`*`): 설정 시간 내 무응답 이해, 반드시 라우터/경로 장애는 아님을 독립 설명 필요.
- 문제 4(`mgr->ttl++` / `update_echopkt`): 최초 모름, 'TTL이 줄지 않는다' 오개념이 나타났으며 **프로그램 TTL 증가 vs 라우터 TTL 감소** 차이를 추가 학습. `mgr->ttl` → `msg.iphdr` → 송신 buffer 3층을 본인 말로 다시 설명하는 검증 필요.

**주의:** 보충 질문에 한번 맞았다고 W01-L01을 'passed'로 바꾸지 않는다.
